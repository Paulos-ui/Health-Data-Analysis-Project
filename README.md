# Health Data Analysis Project 🩺

This project connects Microsoft SQL Server with Power BI to analyze hospital data and provide actionable insights.

## 🔧 Tools Used
- Microsoft SQL Server
- Power BI Desktop
- GitHub

## 🗃️ Data Structure
- Fact Table: Visits
- Dimension Tables: Patients, Doctors, Departments, Diagnosis

## ⚙️ Process Flow
1. Imported raw health dataset into SQL Server
2. Created fact and dimension tables with PK/FK relationships
3. Performed data cleaning using SQL
4. Visualized insights using Power BI (Connected directly to SQL)

## 📊 Insights Extracted
- Most visited department
- Highest treatment costs by doctor
- Gender-based visit distribution
